# atm328p_keyboard

Клавиатура 4×4 на ATmega328P — I²C-ведомый для основного модуля STM32F407.
Общаться с пользователем по-русски.

## Перед работой

1. Прочитать `docs/DECISIONS.md` — состояние, открытые вопросы, принятые решения.
   **Не переспрашивать то, что там уже записано**, и не пересматривать принятые решения
   без новой причины.
2. Проект ведётся **только в Claude Code** (веб-чат по нему закрыт с 2026-10-03),
   поэтому журнал — единственное место, где хранится история.

## После работы

Каждое новое решение, измерение или факт о железе (частота, питание, фьюзы, схема)
записывать в `docs/DECISIONS.md`: обновить таблицу состояния и открытые вопросы,
добавить строку в хронологию с датой. Писать **почему**, а не только что.

## Git

- Репозиторий: https://github.com/granel2/atm328p_keyboard, ветка `main`. `gh` не установлен.
- Коммитить и пушить — когда пользователь просит. Сообщения коммитов — по-английски.

## Сборка и прошивка

- Сборка: `pio run` (рабочая) / `pio run -e clocktest` (тест частоты и питания) /
  `pio run -e uarttest` (тест модуля через UART 38400 без STM32).
  pio: `%USERPROFILE%\.platformio\penv\Scripts\pio.exe`.
- Прошивка — пользователь шьёт сам через **PROGISP 1.72** (USBasp):
  `Load Flash` → `.pio\build\<env>\firmware.hex` → `Auto`.
- **Фьюзы не менять** и не предлагать «Set Fuses»/«Burn Bootloader», пока в DECISIONS.md
  не записаны прочитанные значения. Неверный фьюз тактирования блокирует чип.
- После правки `platformio.ini` или добавления файлов — `pio run -t compiledb` (для clangd).
- В PowerShell 5.1 не писать файлы через `Set-Content`/`-replace` — портит UTF-8 (кириллицу).

## Код

- `include/protocol.h` — протокол, общий с проектом STM32: без Arduino, только `stdint.h`.
  Любое изменение протокола — согласовать с обеими сторонами и записать в DECISIONS.md.
- `include/config.h` — ножки, раскладка, тайминги, значения по умолчанию.
- `src/main.cpp` — рабочая прошивка; `src/clocktest.cpp` — только окружение `clocktest`.
